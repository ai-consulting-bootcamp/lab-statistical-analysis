# LAB | In God we trust, everyone else bring the data

**Seven observed marketing delivery segments • $500,000 hypothetical monthly budget**

**Start at [`lab_proof.md`](lab_proof.md)** after running the sourced dataset analysis. Until then, the generated fixture files under `demo_*` are **test evidence only**, not the submission result.

## Dataset and honesty

- **External source:** [Digital Marketing Performance Dataset (30k), mirrored on Hugging Face](https://huggingface.co/datasets/jason1966/alinaboulsi_digital-marketing-performance-dataset). The publisher describes it as **synthetic, benchmark-based**, not actual client campaign logs. The page states license **unknown**.
- **Original source as described by publisher:** Kaggle (see the dataset card). [Data dictionary](https://huggingface.co/datasets/jason1966/alinaboulsi_digital-marketing-performance-dataset/blob/main/data_dictionary.csv).
- **Evaluation scope:** The source has **six observed platforms**, not seven. To support seven comparisons without fabricating a platform, the pipeline splits one platform into two mutually exclusive, actually observed *placement* segments, with five other platforms unchanged. These are seven **allocation groups**, not seven independent advertising platforms. The rule requires at least 25 active days in each resulting segment.
- **Business limitation:** Revenue is a synthetic proxy, source rows are not randomized and uplift cannot be estimated. Budget is a hypothetical, capped sensitivity scenario; not real optimization.

## Run (Mac / VS Code)

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_lab.py --source hf
```

`run_lab.py --source hf` **downloads the public CSV**, validates it, uses seven observed platform/placement segments, computes KPIs/tests/corrections/power, and generates all final artifacts and an actual [`lab_proof.md`](lab_proof.md). No API key required.

If download fails, fetch the source file manually and re-run the command:

```bash
mkdir -p data
curl -fL 'https://huggingface.co/datasets/jason1966/alinaboulsi_digital-marketing-performance-dataset/resolve/main/digital_marketing_dataset_30k.csv' -o data/digital_marketing_dataset_30k.csv
python run_lab.py --source hf
```

For local test output **only** (no external source): `python run_lab.py --source demo`. It writes separately to `demo_data`, `demo_figures`, and `demo_results`, and will never overwrite the source-data memo or proof.

## Methodology in one paragraph

Aggregate first to day × channel to avoid treating every overlapping campaign as an independent day. Calculate aggregate CTR, conversion rate, CPA and ROAS from summed counts and currency, while keeping daily CPA for Welch comparisons. Run **21 unordered pairs of observed segments** for each of two continuous-metric families (CPA and ROAS) and one Fisher exact conversion family. Apply Bonferroni and BH **within each family**, with full cross-family multiplicity noted as a further limitation. Report effect sizes, percentile-bootstrap intervals and Monte Carlo planning assumptions. This is a sensitivity and association analysis, **not** proof of the causal value of reallocating spend.

## Limits

The two versions of CPA differ: aggregate spend / conversions vs average of daily spend / conversions; the report labels each. Zero-conversion days do not have finite daily CPA and are excluded from the Welch CPA comparison (a potential selection bias). Fisher clicks are not necessarily independent users; repeated ad exposures, shared campaigns and attribution distort p-values. Bootstrap assumes independent days. Revenue is not margin. Publication permission for original raw data is not established; the raw download is intentionally excluded from GitHub.
