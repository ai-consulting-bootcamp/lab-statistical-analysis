# Statistical Analysis Lab: Marketing Channel Budget Allocation

Marketing analyst scenario: compare 3 ad channels (Google Ads, Meta Ads, TikTok Ads) with proper statistical rigor, then recommend how to split a $500K monthly budget.

## How to run

1. Create a Python environment with `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy` (1.11+, for `false_discovery_control`), and `nbformat`/`jupyter` to open the notebooks.
2. Run the notebooks in this order, since each one depends on the file the previous one saves:
   1. `data_exploration.ipynb` (creates `data/marketing_data.csv`)
   2. `statistical_analysis.ipynb`
   3. `power_analysis.ipynb`
   4. `business_recommendations.ipynb`
3. `executive_memo.md` is a plain markdown file, no need to run anything for it, it already has the final numbers written in.

## File map

| File / folder | What it is |
|---|---|
| `data/raw/global_ads_performance_dataset.csv` | Original dataset downloaded from Kaggle, not modified |
| `data/marketing_data.csv` | Cleaned dataset, aggregated to one row per channel per day, produced by `data_exploration.ipynb` |
| `data_exploration.ipynb` | Dataset choice, loading, cleaning, first look at channel metrics and distributions |
| `statistical_analysis.ipynb` | t-tests and Fisher's exact test between channel pairs, plus Bonferroni and FDR correction |
| `power_analysis.ipynb` | Simulated power curves, minimum sample size needed, and a check on whether 90 days of data was enough |
| `business_recommendations.ipynb` | Bootstrap confidence intervals, composite channel ranking, and the budget allocation table |
| `executive_memo.md` | Final write up with findings, recommendation, and caveats |
| `reflection.md` | Short reflection on the lab |
| `group_metrics_overview.png`, `group_distributions.png` | Charts from `data_exploration.ipynb` |
| `metric_comparison_heatmap.png`, `rate_comparison.png`, `correction_comparison.png` | Charts from `statistical_analysis.ipynb` |
| `power_analysis_cpa.png` | Chart from `power_analysis.ipynb` |

## Setup assumptions

- The dataset (Global Ads Performance: Google, Meta, TikTok) is a real, public Kaggle dataset, but its values are synthetically generated by the dataset author, not the company's own data. See `executive_memo.md` for the full caveat on this.
- All 4 notebooks assume they are run from this folder (`lab_statistical_analysis_zahra/`), since the code paths are relative (for example `data/marketing_data.csv`).
