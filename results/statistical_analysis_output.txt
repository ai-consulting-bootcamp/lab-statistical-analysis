==============================================================================
STEP 6.1: THE MULTIPLE-COMPARISONS PROBLEM
==============================================================================
Primary family: 15 CPA t-tests + 15 conversion-rate Fisher tests = 30
Expected false positives at alpha=0.05 if every null were true: 30 x 0.05 = 1.5
P(at least one false positive) if all nulls true: 1 - 0.95^30 = 79%
So some 'significant' results in an uncorrected table are expected to be noise.

KEY INSIGHTS
==============================================================================
- 14/15 CPA gaps survive FDR; exceptions: Snapchat vs TikTok (p_fdr=0.20, d=-0.14).
- These channels differ by multiples, not percentages, so correction barely changes the picture.
  Its value shows up exactly at the margin: the near-tied mid-tier pairs.
- FDR is the better default for a budget review (we accept a few false leads to keep power);
  Bonferroni fits when a single false positive is costly, e.g. killing a channel outright.
